# Zodd — 3D Portfolio

The immersive portfolio of Ahmad Nura (Zodd), a full-stack developer, Web3 builder, and 3D creator.

Built from the MIT-licensed 3D portfolio template by Akash Malhotra and adapted for the 3D Websites Hackathon. Features React, TypeScript, Vite, Three.js, React Three Fiber, Drei, and GSAP.

Connect: [GitHub](https://github.com/heiszodd) · [Telegram](https://t.me/zoddspace)

Run locally with `npm install && npm run dev`. Build with `npm run build`.
